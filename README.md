# VOXA

**English** · [简体中文](./README.zh-CN.md)

> Turn your Apple TV Siri Remote into a natural remote input device for your Mac.

[![Latest release](https://img.shields.io/badge/latest-1.1.3%20(Build%2037)-007AFF)](https://github.com/jinzongma/voxa/releases/latest)
[![macOS](https://img.shields.io/badge/macOS-13%2B-111111?logo=apple)](https://github.com/jinzongma/voxa/releases/latest)
[![Apple Silicon](https://img.shields.io/badge/Apple%20Silicon-supported-34C759)](https://github.com/jinzongma/voxa/releases/latest)

VOXA provides button mapping, touch controls, Shortcuts integration, and automatic scene switching based on the foreground app. Microphone Edition can also use the built-in microphone on a supported Siri Remote as an audio input device for your Mac.

## Download

**[Download VOXA 1.1.3 (Build 37)](https://github.com/jinzongma/voxa/releases/latest)**

- Apple Silicon Mac
- macOS 13 Ventura or later
- Apple TV Siri Remote paired in macOS Bluetooth settings
- Developer ID signed and notarized by Apple

See the [Installation & User Guide](./VOXA-User-Guide.md) for detailed instructions.

## Highlights

- **Flexible mapping:** Assign remote buttons to keys, keyboard shortcuts, or common actions.
- **App scenes:** Automatically apply a different mapping for the foreground app.
- **Touch and clickpad ring:** Control the pointer, scroll, or switch apps.
- **Shortcuts:** Browse and run macOS Shortcuts directly.
- **Microphone input:** Microphone Edition supports using a compatible Siri Remote as a Mac microphone.
