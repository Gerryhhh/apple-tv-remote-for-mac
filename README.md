# Voxa

**English** | [简体中文](./README.zh-CN.md)

Voxa turns an Apple TV Siri Remote into a remote input device for your Mac, with button mapping, touch controls, and configurable scenes.

Microphone Edition (paid) lets you use the built-in microphone on a supported Apple TV Siri Remote directly as a microphone input on your Mac.

- Current version: **Voxa 1.0.12 (Build 16)**
- Requirements: Apple Silicon Mac, macOS 13 Ventura or later, and an Apple TV Siri Remote
- Download: get the DMG installer and user guides from [Releases](https://github.com/jinzongma/voxa/releases).
- Guide: [Installation & User Guide](./VOXA-1.0.12-User-Guide.md)
