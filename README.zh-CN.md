# Voxa

[English](./README.md) | **简体中文**

Voxa 把 Apple TV Siri Remote 变成 Mac 的遥控输入设备，支持按键映射、触控操作和场景切换。

麦克风版（付费功能）可将支持的 Apple TV Siri Remote 内置麦克风直接作为 Mac 的麦克风使用。

- 当前版本：**Voxa 1.0.12（Build 16）**
- 系统要求：Apple Silicon Mac、macOS 13 Ventura 或更高版本、Apple TV Siri Remote
- 下载：从 [Releases](https://github.com/jinzongma/voxa/releases) 获取 DMG 安装包和使用教程。
- 教程：[安装与使用教程](./VOXA-1.0.12-User-Guide.zh-CN.md)
